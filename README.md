# Exercícios UEG
Exercícios realizados ao longo do curso de graduação Sistemas para Internet na Universidade Estadual de Goiás (UEG).

Primeiro Semestre - Matérias
* Algoritmos e Lógica de Programação: Esta matéria teve foco em introduzir conceitos básicos de computação dentro do desenvolvimento de softwares e estimular a prática de estruturas lógicas essenciais para a criação de programas. Por estar num contexto de um curso com foco em desenvolvimento web, a linguagem utilizada foi o Javascript, explicando sua sintaxe e sua flexibilidade e integração com HTML e CSS como três componentes primordiais para a criação de websites.
* Ao longo de toda a matéria aprendemos: Variáveis, Estruturas condicionais simples e compostas, estruturas de repetição e vetores.
  * Uso de variáveis e como servem como armazenadoras de dados de diferentes tipos(Strings, Números, Valores booleanos) e os      tipos de variáveis que possuem valor que será alterado e variáveis de valor constante (let/const)
  * Estruturas Condicionais simples, o conceito de executar uma ação caso cumpra uma condição e caso não cumpra siga o fluxo      sequencial do programa (if). Estruturas Condicionais Compostas, o uso de estruturas condicionais que definem valores para um mesmo dado ou instruções completas para diferentes condições quando cumpridas (if/else if/else | switch/case).
  * Estruturas de Repetição, o conceito de executar um bloco de código enquanto determinadas condições forem cumpridas, sua utilidade para manipular dados que se multiplicam dispensando a digitação de multiplas linhas de código criando redundâncias e evitando trabalho excessivo, entre outras finalidades como a escrita de mensagens de maneira automática na tela e operações matemáticas que são autossuficientes quando determinados os limites de seus valores. Foram explicadas as três sintaxes mais conhecidas para criação de laços (while/do while/for) e em que cenários são mais adequadas, explicando o conceito de loops onde há noção do ponto exato de parada e em outros onde o laço não possui um ponto de parada bem definido e acontece enquanto uma determinada lógica se torne diferente.
  * Vetores, como último conceito apresentado na matéria, porém somente de maneira conceitual sem muita aplicação prática devido a impedimentos no ritmo de aprendizado da classe como um todo. Introduziu o conceito de um vetor, operando como uma váriavel composta, ou seja, uma variável que possui múltiplos valores, sua estrutura como seus valores de índice e valores armazenados dentro dessas posições. Foi bastante ressaltado pelos professores, a utilização de estruturas de repetição para a manipulação de vetores e como percorrer seus valores.
